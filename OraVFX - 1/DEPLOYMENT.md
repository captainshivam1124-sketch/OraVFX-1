# OraVFX production deployment

## Requirements
- Node.js 18+ (Node.js 20+ recommended)
- A Node-compatible host with a persistent writable volume/directory
- HTTPS in production

## Environment variables
Copy `.env.example` to your host's environment settings (do not commit `.env`).

Required for production:
- `NODE_ENV=production`
- `ADMIN_PASSWORD` — long random password; never use the development password
- `DATA_DIR` — persistent writable directory for inquiries, orders and packages

For Razorpay online payments also set:
- `RAZORPAY_KEY_ID`
- `RAZORPAY_KEY_SECRET`
- `RAZORPAY_WEBHOOK_SECRET`

Set `TRUST_PROXY=1` when the app is behind a reverse proxy/load balancer (common on managed hosts).

## Start
```bash
npm start
```
The server listens on `PORT` (default `4173`).

## Health check
Use `GET /health` as the hosting platform health-check endpoint.

## Persistent data — important
The app intentionally keeps the existing JSON data model so the admin panel continues to work without changing the frontend. The directory configured by `DATA_DIR` **must be persistent**. Do not deploy this app to a serverless/ephemeral filesystem if you need inquiries, orders, package edits, and uploaded client files to survive restarts or redeploys.

The server writes JSON atomically to reduce corruption during concurrent/restarted writes. Back up `DATA_DIR` regularly.

## Admin
Open `/admin`. Authentication is password-only and the password is read from `ADMIN_PASSWORD` in production. Login is rate-limited per client IP. The session cookie is HttpOnly, SameSite=Strict and Secure in production.

## Razorpay webhook
Configure Razorpay's webhook endpoint as:
`https://YOUR-DOMAIN/api/webhooks/payment`

Use the same value as `RAZORPAY_WEBHOOK_SECRET` in the host environment.

## SEO
The public site is served at `/ora/`. `robots.txt` and `sitemap.xml` are generated by the server. Submit the final sitemap URL to Google Search Console after deployment.

## Before going live
1. Set a unique strong `ADMIN_PASSWORD`.
2. Confirm `DATA_DIR` is on persistent storage.
3. Confirm HTTPS is active.
4. Set Razorpay live credentials if online payment is required.
5. Test `/health`, `/ora/`, `/admin`, inquiry submission, admin inquiry viewing, package editing, order creation, payment verification and webhook delivery.
6. Make a backup of the initial `DATA_DIR`.
