Important deployment note:
The app keeps the existing JSON data model so the current admin panel and frontend continue to work without a database migration. DATA_DIR MUST point to persistent writable storage on the production host. Do not use an ephemeral/serverless filesystem if inquiries, orders, package edits or uploaded client files must survive restarts/redeploys.

The public site is served at /ora/. The current canonical and structured-data URLs use /ora/. If the final production domain/path differs, update the SEO URLs to the final public URL before Google Search Console submission.

Razorpay credentials are intentionally not included in the ZIP. Set them as hosting environment variables. Never put live secrets in frontend code or commit them to Git.
